# Purpose

- Hold the LTMS software engineering project and its shared Git repository.
- This repository is a collaboration workspace for approximately 10–14 group members.

# Ownership

- The repository is shared by the project group; authorized collaborators may push changes.
- The `origin` remote is the group's GitHub repository: `https://github.com/Pnd0805/Project-SoeftwareEn-LTMS.git`.

# Local Contracts

- Treat changes, branches, and history as shared group work; preserve existing work unless the task explicitly targets it.
- Do not assume `main` or another branch is the sync target. Inspect the current branch and its upstream with `git status --short --branch` and `git branch -vv` before pulling.
- Preserve uncommitted local changes and do not pull over a dirty worktree without explicitly deciding how those changes will be handled.
- Pull only from the current branch's configured upstream after confirming that branch is the intended one.
- Keep course PDFs and downloaded/reference materials stable unless the task explicitly asks to change them.

# Verification

- Before and after Git operations, verify the branch, upstream, worktree status, and latest commit.
- Run local verification only inside the specific source subtree being changed.
