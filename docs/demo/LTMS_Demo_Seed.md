## วิธีนำไปใช้บนเครื่อง deploy

1. ให้ backend บนเครื่อง deploy เป็นรุ่นที่ migration ถึง `050` หรือใหม่กว่า
2. restore ไฟล์ลงฐานข้อมูล (ไฟล์จะลบและสร้างทุกตารางใหม่):

```bash
mysql -u<user> -p --default-character-set=utf8mb4 <database> < demo-seed.sql
```

3. ถ้า backend ใหม่กว่า `050` ให้รัน migration ต่อ:

```bash
npm run migrate
```

4. ตรวจว่าฐานข้อมูลตั้งเวลาเป็น UTC เวลาทั้งหมดในไฟล์เก็บเป็น UTC ถ้าฐานใช้เขตเวลาอื่น ช่วงเวลาของแมตช์สดจะเลื่อน

## วิธีสร้างใหม่ (เมื่อเลื่อนวันหรือเวลา)

สคริปต์ **ล้างฐานข้อมูลทั้งหมด** ก่อนสร้าง ต้องมี backend รันอยู่ที่ `localhost:8000` และ container `ltms-mysql`

```bash
python database/seed-demo.py 2026-10-09T13:00
```

จากนั้น dump ใหม่เพื่อนำไป restore:

```bash
docker exec ltms-mysql mysqldump -uroot -p<password> --default-character-set=utf8mb4 --single-transaction --add-drop-table --routines --triggers --skip-comments ltms > demo-seed.sql
```

## ที่ต่างจากแผนที่เสนอไว้

- **ทัวร์ 10 ไม่ได้เล่นแมตช์** โหมดออนไลน์ต้องเช็คอินด้วยรูปถ่าย ซึ่งต้องมีที่เก็บไฟล์ จึงค้างไว้ที่ขั้นนัดแข่งพร้อมรหัสห้อง
- **เอกสารของกรรมการภายนอกเป็นคีย์ที่ไม่มีไฟล์จริง** ใส่ด้วย SQL เพื่อให้คิวแอดมินกดอนุมัติได้
- **เวลาของแมตช์ที่แข่งไปแล้วถูกย้อนด้วย SQL** (ทัวร์ 8, 9, 11) เพราะระบบไม่ให้เริ่มแมตช์นอกช่วงเวลานัด ผลแข่ง การยืนยัน และคะแนน Pick'em มาจากการเล่นผ่านระบบจริง
