## 1. For the backend team

### The QA baseline needs re-saving

Three items in `BACKEND-GAPS.md`, all the same root: `qa-baseline.sql` was saved on
21 September, and the backend has moved on.

- **`FE-migration-029-fails-on-baseline` (widened).** `restore` loads a
  `--add-drop-table` dump, which drops only the tables inside it. Tables made by
  later migrations survive, so `npm run migrate` fails on **024** and **028**
  (`ER_TABLE_EXISTS_ERROR`) as well as **029** (`ER_DUP_FIELDNAME`), and 030 is
  never applied. Without migrate at all, match pages and standings answer 500.
  *Wanted:* re-save the baseline at the current schema with `schema_migrations`
  complete, and make `restore` drop the whole database first.

  not enough on its own: five of those tournaments are already public, and
  taking their conflicted referees out leaves them below the minimum
  `REFEREES_INCOMPLETE` enforces. A fixed baseline needs replacements.

  - t12 is closed with no champion, so its page says "No champion was assigned".
  - Eight played matches have no start/end timestamps; nothing reads those yet.

### R38 · Step 6 counts referees

`SetupTrail.tsx` is slice 2's; the change was approved by the user and is small.

- **Cause.** In real mode "Set every fixture" was done once every match had a
  kick-off, an end time and a venue. Its own label says "and the officials". t23
  moved on to "Results come in" while match 13 had 0 of 2 referees — a match M10
  refuses to start.
- **Fix.** The step now also needs F14 `GET /tournaments/:id/referees/coverage` to
  report every match covered — the backend's own count, not ours.
  - `getRefereeCoverage` (`api/admin.ts`) now keeps `uncoveredMatchIds`; it used
    to fold them into totals.
  - The note reads "N of M have all their referees".
  - When fixtures are set but referees are missing, the button opens Manage →
    Draw, where the per-match planner lives.
  - Coverage that cannot be read says so; it never passes silently.
- **Tests.** Two new tests in `DrawProgress.test.tsx`, both failing without the
  fix.
- **Verified live.** t23 → step 7, "1 of 1 have all their referees"; t22 → step 6,
  "0 of 1".

**For slice 2:** round-robin tournaments have no Draw tab, so the per-match
referee planner never renders for them (`ManageTab.tsx`, `showDraw`). Step 6's
button falls back to the schedule there.

### R36 · `restore-qa.py`, and an audit that knows more

**Never run `qa-baseline.py restore` on its own.** Run this instead, with the
backend running:

```bash
python frontend/scripts/restore-qa.py
```

It works in this order:

1. Restores the baseline.
2. Runs migrate. A failed migration is skipped only when its table already
   exists and is empty, or its columns already exist; anything else stops the
   script.
3. Re-adds the faculty admin and root.
4. Hands the organizer role over in the three tournaments where the organizer
   also competes.
5. Removes the conflicted referees through F03.
6. Re-staffs the five public tournaments that step 5 leaves short.
7. Repairs match #1 and staffs match 13.
8. Finishes match 12 and sets t12's champion.

It ends by running the audit, which should exit 0. Each repair is a decision the
user made; it never infers one.

`audit-roles.py` now checks eight rules. The two new ones:

- **C7** — a public tournament with fewer accepted referees than publishing
  requires;
- **C8** — a match past `scheduled` without a start, end and venue.

Both exist because fixing one rule broke another.
