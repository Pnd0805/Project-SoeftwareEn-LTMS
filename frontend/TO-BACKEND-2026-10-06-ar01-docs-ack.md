## ② AR01 — แยก "เปิดเอกสารไม่ได้" ออกจาก "ไม่มีเอกสาร"

| เคส | จอแสดง |
|---|---|
| มีลิงก์ | ชื่อไฟล์เป็นลิงก์ (ตัด query ของลายเซ็นออก) เปิดในแท็บใหม่ · ภาพมี preview |
| ภาพโหลดไม่ขึ้น (403/404) | "เปิดเอกสารไม่ได้ — ลิงก์อาจหมดอายุหรือไฟล์ไม่อยู่ในที่เก็บแล้ว ลองรีเฟรชคิว ถ้ายังเปิดไม่ได้ให้กด Request documents" + ปุ่ม **Refresh queue** |
| คิวค้างเกิน 18 นาที | "ลิงก์เอกสารมีอายุ 20 นาทีและน่าจะหมดแล้ว" + ปุ่ม Refresh queue · เผื่อเวลา 2 นาทีไว้สำหรับคนที่กดลิงก์ช่วงใกล้หมดอายุ |
| `docsSubmitted: true` แต่ `docs: []` | "ส่งเอกสารแล้วแต่ไม่ได้รับลิงก์" + Refresh queue |
| `docsSubmitted: false` | "ยังไม่มีเอกสาร" (เหมือนเดิม) |

- **PDF:** ตรวจข้าม origin ไม่ได้ว่าเปิดได้ไหม เลยใช้คำเตือนเรื่องอายุลิงก์อย่างเดียว ตอนนี้ U12 รับแค่ JPEG/PNG จึงยังไม่กระทบ
- **ลิงก์ที่ไม่ใช่ `http(s)`:** ไม่ทำเป็นลิงก์ เพื่อกัน `javascript:` ใน href
- **ยืนยันบนข้อมูลจริงแล้ว:** แถวของ 9053 (สมเกียรติ, ทัวร์ 19) เปิดลิงก์แล้ว MinIO ตอบ **404** จอขึ้นสถานะ "เปิดเอกสารไม่ได้" ตามคาด และกด Refresh queue แล้วระบบเรียก AR01 ใหม่
- **ธงบอกสถานะรายไฟล์:** ยังไม่ต้องทำ ตามที่เสนอมา
