# 02: Browse and preview Tournaments

**What to build:** Preserve A's Tournament card discovery inside the new workspace, with a read-only popup that lets a person inspect the selected Tournament and continue to its full page.

**Blocked by:** 01 — Find the next task from Home.

**Status:** draft — ready for breakdown review.

- [ ] Search, sport, Stage and relationship categories retain their current results and meanings.
- [ ] Selecting a card opens a named preview showing only facts supported by the permitted list data.
- [ ] The full-page action retains the card's existing public or management destination.
- [ ] Close, Escape and browser Back restore the browsing context; keyboard focus returns to the originating card when it remains available.
- [ ] Preview selection preserves other query parameters and does not issue a new request for an unknown identifier.
- [ ] Unknown facts remain unknown; removal or access loss of the selected record closes its preview.
